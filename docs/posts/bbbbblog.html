天天的Blog，筛选俺的笔记库。

为什么又做Blog。
1.半个保持持续学习。
2.本地笔记库需要筛选。

写字的地方。

放进来的都是旧东西：一个梦，一段路，临过的帖，修不好的设备。把乱的理成顺的。

仓库

一个静态博客。没有框架，没有依赖：Markdown 放在 posts/，一个 Node 脚本把它们拼成 docs/，交给 GitHub Pages。

和笔记库没有关系。 笔记库是给自己看的，很杂，不对外；这里只放挑出来的。

写什么

  • 梦。记得清的梦都写下来。醒来先记草稿，隔几天再改，一个梦写两三稿是常事。写下来就够了，不解释。
  • 日课。临帖、刻章、英语、手账。
  • 技术。踩过的坑，修好的东西，留个记录，省得下次再踩。

以上是这么打算。

目录

posts/            文章，一篇一个 .md
theme/style.css   全部样式，就这一个文件
theme/home.js     首页视差
scene.mjs         黄昏山景，SVG 现画
about.md          关于页
site.json         站名、副标题、作者、地址
build.mjs         生成器，零依赖，Node 18+
dev.mjs           本地编辑器 + 预览服务，编辑博客.bat 跑的就是它
docs/             生成出来的网页；别手改，由 build 重建

还有写字这件事，从日记本搬到网页上，坐下来，写完关灯。

——先写写，再多看看。
